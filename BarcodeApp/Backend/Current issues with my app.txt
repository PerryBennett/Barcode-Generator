Understanding getGrayScaleData()

what is the advantage of converting RGB image to grayscale brightness value ?

	text detection depends on contrast, not color
	variance becomes meaningful only in grayscale

	no longer care about color 
	treat the image like a 2D grid of intensity values 

	makes edge detection, thresholding, text detection much simpler

Understanding getVariance
Variance is a measure of how spread out values are. 
	in my case im analyzing numbers in general - analyzing pixel brightness values in gray 

[120, 121, 119, 120] -> variance is low 

variables jump around -> [10,240,30,200,90] variance is high 

measuring how much things change

Four gray array:
	compute the mean (average brightness) 
	for each pixel 
		subtract mean
		square the result 	
	average those squared differences 

result = a single number representing overall variability

significance = working with video frames converted into brightness values. 
low variance = stable / uniform frame 


variance = is this frame visually varied enough to be interesting
variance = average squared distance of pixel brightness values from their mean (a measure of how spread out the image is)
